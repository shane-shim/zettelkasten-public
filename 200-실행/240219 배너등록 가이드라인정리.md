# 240219 배너등록 가이드라인정리

#200-실행

상황 : 카카오배너 규격은 테스트 모델에서 width : 350px로 했을때 정확히 맞아 떨어짐. 하지만 실제 페이지에서  width : 550 px 로 맞춰야 딱 맞아 떨어진다. 

배운점: 테스트 모델과 실제 환경과의 차이로 인해 적용값이 매번 달라진다. 따라서 실제환경에서 해야하며, div width 값을 적용하면 컨트롤이 가능해진다.
반추 : 어떤 간격으로 진행해야할지 가이드라인에 대한 정립이 필요해보인다. 이 부분이 정립되지 않으면 나중에 인수인계할 때 작업자가 어떠한 환경 어떻게 일해야하는지 다 조사해야하는 불편함이 있다. 이러한 프로세스를 만들어 작업속도를 빠르게 하는 것이 중요해보인다. 글로만으로도 정리해도 좋다.

가이드라인 : 
```html
style="width:550px; height:100px; margin: 5px 0px 15px 0px;
```
