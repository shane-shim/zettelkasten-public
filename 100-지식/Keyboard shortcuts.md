# Keyboard shortcuts
**Global Shortcuts**
- Search in Archive
    - MacOS: CMD + F
    - Other: CTRL + F
- Open Spotlight
    - MacOS: CMD + SHIFT + K
    - Other: CTRL + SHIFT + K
- Toggle Sidebar
    - MacOS: CMD + SHIFT + E
    - Other: CTRL + SHIFT + E
- Close all open Doc windows
    - MacOS: Shift + ESC
    - Other: Shift + ESC
- Move the cursor to the next open Doc
    - MacOS: CMD + K
    - Other: CTRL + K
- Move the cursor to the previous open Doc
    - MacOS: CMD + J
    - Other: CTRL + J
- Zoom In
    - MacOS: CMD + Plus (+)
    - Other: CTRL + Plus (+)
- Zoom Out
    - MacOS: CMD + Minus (-)
    - Other: CTRL + Minus (-)
- Select multiple docs from the Sidebar
    - Shift + Click
- Open a Doc on the Sidebar in focus mode
    - MacOS: CMD + Click
    - Other: CTRL + Click
- Remove a starred item from the Sidebar
    - MacOS: Option + Click
    - Other: Alt + Click
- Open/close the left Sidebar
    - MacOS: CMD + SHIFT + E
    - Other: CTRL + SHIFT + E
**Desk/Board Shortcuts**
- Select all docs
    - MacOS: CMD+A
    - Other: CTRL+A
- Undo
    - MacOS: CMD + Z
    - Other: CTRL + Z
- Redo
    - MacOS: CMD + SHIFT + Z
    - Other: CTRL + SHIFT + Z
- Copy elements
    - MacOS: CMD+C
    - Other: CTRL+C
- Cut elements
    - MacOS: CMD+X
    - Other: CTRL+X
- Paste elements
    - MacOS: CMD+V
    - Other: CTRL+V
- Quick drag
    - Press and hold the spacebar and drag
- Create a new Doc
    - Press D key
- Toggle dragging
    - Press M key
**Text Editor Shortcuts**
- Close doc window
    - ESC
- Close focus mode
    - ESC
- Close focus mode split view
    - ESC
- Enter focus mode
    - MacOS: CMD + Shift + Enter
    - Other: CTRL + Shift + Enter
- Search in text
    - MacOS: CMD + F
    - Other: CTRL + F
- Turn selected text into a link
    - MacOS: Option + L
    - Other: Alt + L
- Open the link under the cursor (external or internal)
    - MacOS: Option + O
    - Other: Alt + O
- Bold text
    - MacOS: CMD + B
    - Other: CTRL + B
- Italic text
    - MacOS: CMD + I
    - Other: CTRL + I
- Underlined text
    - MacOS: CMD + U
    - Other: CTRL + U
- Strikethrough text
    - MacOS: CMD + SHIFT + X
    - Other: CTRL + SHIFT + X
- Undo
    - MacOS: CMD + Z
    - Other: CTRL + Z
- Redo
    - MacOS: CMD + SHIFT + Z
    - Other: CTRL + SHIFT + Z
- Bullet list
    - SHIFT + CTRL + 8
- Ordered list
    - SHIFT + CTRL + 9
- Horizontal Rule
    - MacOS: CMD + _
    - Other: CTRL + _
