# 터미널을 내리면 서버가 끊기는 현상에 대하여..

```
<문제점> 
터미널을 foreground에서 실행시 종료하면 서버에 443 오류가 발생하는 현상 

<문제의 맥락> 
1. 노트북 ip로 접속하면 public ip로 읽힌다.
2. public ip는 private ip로 치환된다. 
3. 치환된 키는 포트 80과 443으로 접근할 수 있다.
4. 443으로 접근한실 local 3000을 읽지 못하는 현상이 발생한다.
5. local 3000은 즉 node를 의미한다.

<문제의 해결>
foreground에서 빌드를 하는 것이 아닌 
screen 명령어를 써서 background로 실행을 하고,
foregrond에서 종료하면 문제가 해결됨. 

<현재 추가 문제> 
누구나 퍼블릭으로 접근할수 있어 보안이 매우 취약하며,
서버 빌드/배포 자동화가 되지 않아 도커도입이 필수다.
또한 mysql(3306)도 열려있어 누구나 데이터에 접근할 수 있기 때문에 
도커 혹은 ELB로 보안을 강화해야한다. 

참고 사이트
<https://helloitstory.tistory.com/132>

```
