# 옴니전트의 장기 기억 인프라

#100-지식 #옴니전트 #장기기억 #OLTP #AI에이전트

옴니전트에서 장기 기억 인프라는 에이전트 세션의 컨텍스트 유실을 막기 위한 상태 저장 계층이다. 컨테이너 종료, 세션 크래시, 실행 노드 교체가 발생해도 대화 스냅샷과 실행 상태를 복원할 수 있어야 한다.

## 명시적 지식
NotebookLM 자료에서는 Lakebase Postgres 같은 저지연 OLTP 저장소를 세션 상태 저장소로 결합하는 방안이 언급됐다. 목적은 단순 파일 저장보다 빠르고 일관적인 상태 보존, 35일 범위의 시점 복원, 분기 실험이 가능한 구조를 만드는 것이다.

## 실무 의미
여러 하네스와 VM을 동시에 운용하면 “지금 어떤 에이전트가 어떤 상태였는가”가 핵심 운영 정보가 된다. 장기 기억 인프라가 없으면 에이전트 오케스트레이션은 세션이 끊길 때마다 다시 수동 복구해야 하는 불안정한 워크플로가 된다.
