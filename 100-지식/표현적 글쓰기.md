# 표현적 글쓰기

#100-지식 #resource

#resource 
<aside> 💡 Expressive Writing : 표현적 글쓰기를 통해 심리상담 효과 내기. 표현적 글쓰기를 하면 성적이 오르고, 건강해지고, 대인관계가 좋아지고 심지어 상처도 빨리 낫는다.
</aside>
### 세션의 배경
OT에서 기분이 상한 분이 많다는 사실을 알게됨. 3가지의 세션을 제안, 1. 덜 읽기 2. 표현적 글쓰기 3. 야생 퍼실리테이션
덜 읽기 → 주의 돌리기 2. 표현적 글쓰기 → 감정 들여다보기 3. 야생 퍼실리테이션 → 집단으로 문제 해결하기
### 시작 전 기분 체크 : “나는 마음이 불편한가?” (1-5)
글쓰기의 효과 : 마음의 묶인 매듭을 풀어주는 효과
- 글쓰기는 어떻게 쓰는가에 따라 현재의 내 심리 이해 및 해소에 도움될 수 있다.
- 실제로 글로 자기 상태를 표현한 것만으로도 회복이 더 빨리된 사례가 있다.
- 제대로 했다면 뇌 속을 샤워한 기분이 들 것. : 논리(이성) 보다는 감정(감성)
### 1단계: 자동기술 글 쓰기 (10분)
생각나는 것을 멈추지 말고 자유롭게 쓴다. 욕이나오거나 다른 생각이 나면 그것을 그대로 쓴다
### 2단계: 1단계 중 주제를 좁혀서 쓰기 (10분)
2단계에서는 주제를 좁혀서 계속 쓴다. 쓰다가 교정해도 된다. 1단계에서 쓴 것을 보면 안된다.
### 3단계: 2단계의 소재로 다른 형식으로 써보기
3단계에서는 2에서 쓴 글에 대해 다른 형식, 관점으로 써본다.
- 시쓰기
- 공상과학소설 써보기
- 영화 시나리오
- 수호천사(3인칭)
- 다른 사람의 관점
- 미래의 내가 지금 나에게 쓰는 편지
### 글 쓴 후 기분 체크 (1-5)
글로 표현하기 전보다 나아졌는가?
글쓰기를 3단계로 나누는 이유 : 시점 바꾸기, 인과관계 찾기
### 세션 후 Q&A
1. **글쓴 후, 더 기분이 나빠졌다면 뭐가 문제일까요?**
- 점수가 떨어지면 버지니아 사티어가 말하는 침전일 수 있음. (= 글로 풀어내며 회피했던 것과 대면했기 때문)
- 안 좋은 기억을 서랍속에 넣으면 나중에 튀어나올 수 있기 때문에 소화를 위해 내가 신뢰하는 사람과 대화하거나, 표현적 글쓰기를 한번 더 해볼 것을 추천
- 경쟁적이기 때문에 회피 성향이 있을 수도 있음
    - Type A유형의 사람과 Type B의 사람
          - 경쟁적인 사람은 내 바깥의 목표가 더 중요. 외부를 신경쓰느라 내 안을 들여다보지 못할 가능성 있음

---
1. **저는 왜 전과 후 기분이 나아진 것 같지 않나요?**
- 시작부터 이미 기분이 좋았기 때문에 천장효과, 이미 높은 상태라 효용이 크지 않을 수 있음
- 평소에 글쓰기를 통해 충분한 효용을 얻고있거나, 논리 기반으로 접근해서 그럴 수 있음
- 주어가 바뀌는 사람은 표현적 글쓰기의 benefit이 크고, 안바뀌는 사람은 작고

---
1. **위와 같다면, 일상적인 접근을 시도해볼 수도 있음**
- 3단계 글의 장면에 대해 색깔, 모양, 크기 등으로 표현해본다.
    - 모양은, 크기는, 색깔은? 질감은?
### 과거의 경험을 돌아보는 방법
일상적인 사건들을 회고한다.
- 일상적인 사건들을 떠올려본 뒤, 한 장면을 골라서 그때로 돌아가서 자세히 써본다. 생각하고 있었고 눈에 밟혔지만 감지하지 못했던 것들….
- “이게 기억이 지금 나에게 의미가 있기 때문에 기억이 나는 것이다”라 생각하고 당시 내가 생각했지만 못느낀 것을 탐색해볼 것
- 이를 통해 일상을 더 깊이있게 느끼는 것. 순간의 음미
<aside> 💡 회고 할 때 꼭 대단한 사건(Signigicant Event)은 회고 안해도 강하게 남아있을 가능성 크다. 오히려 일상적인 사건(Insignificant Event) 중에서 왠지 모르겠지만 떠오르는 장면이 있을 것
</aside>
