###### 1. How can I change the color of the docs?
You can change the color of the docs in two ways.
- You can click once on a doc and activate the action bar. Then, you can select the desired color from the change color option.
- You can double-click and open the doc and press the 3 dots icon on the upper right-hand side. You can then select the change color option.
- You can select multiple docs, right-click, and select select change color option.
![image]()
###### 2. How do I make a doc look bigger?
- You can drag from a doc window’s corners and edges to change its size.
- By pressing the Maximise button you can go to focus writing mode. In this mode, you can click on the linked docs, which will open on the side. You can swap the doc in the focus and the side by clicking the swap button on the upper right of the doc. You can resize the sidebar by dragging.
###### 3. What are the embed/upload options?
- You can embed the following elements in docs,
    - YouTube videos
    - Vimeo videos
    - Twitter tweets
    - Images (JPG, PNG)
    - PDFs
- You can upload any file types, including but not limited to:
    - audio files
    - video files
    - text files
- For any embed or upload, you can simply paste links to the text editor. The editor will automatically detect and appropriately display them.
- You can upload any type of file to the text editor by either using the insert menu by typing slash (/) or simply drag and drop.
![image]()
###### 4. Is there a limit on file size that I can upload to a doc?
Yes, we've set a generous file size limit of 200 MB per upload.
###### 5. Can I view my media files outside of the docs?
- You can extract your embedded elements outside of the docs for better viewing. You can double-click on embedded elements and hover the element until you see the icons on the top right corner. Click the extract button to extract the media into a separate doc.
- Remember, this extraction is temporary while you remain on the board or desk.
![image]()
###### 6. What does the action bar do?
The action bar gets activated after clicking once on any doc, text, column, or daily doc. It makes frequently done actions available and easy to take. The options on the action bar are as follows: show links, toggle layout, change color, duplicate, edit title, maximize (go to focus mode), and the three dots option which details further actions.
![image]()
###### 7. Can I change the docs’ layout?
There are three doc layout options: default doc layout, folded doc layout, and title doc layout. You can click once on docs and toggle the layout using the toggle layout option in the action bar. Alternatively, you can press F key to fold/unfold selected docs, and L key to go to the title layout.
###### 8. Can I duplicate docs and other elements?
You can duplicate docs, daily docs, columns, and text elements on desks or on any board. You can click once on any element(s) and select the duplicate option or right-click on the element(s) and select the duplicate option.
###### 9. Can I Copy-Paste docs and other elements?
You can copy docs, daily docs, columns, and text elements on desks or on any board. Then, you can paste the copies on your desk or on any other board. You can right-click on any element(s) and select the copy option.
