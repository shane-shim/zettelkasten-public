###### 1. How do I search among my docs or boards?
The search query is split into words by the blank space, and each word in the search query is searched within the titles and the content of the doc and boards. Search results will show the matched docs chronologically by the modification date.
You would see a “no docs found…” message if no docs matched the search query. Likewise, if no boards matched the search query, you would see a “no boards found…” message.
- **Spotlight Search:** You can access the search view by clicking the Spotlight button on the top right corner of your desk or by pressing the ⌘ + Shift + K (CTRL+Shift+K) combination. With Spotlight, you can search for all your docs and board.
- **Sidebar Search:** When the sidebar is open, you can access the search function for docs with the ⌘ + F (Ctrl + F) combination.
- **Docs:** The sidebar has a “Docs” browse view, where all your docs are ordered chronologically.
- **Boards:** The sidebar has a “Boards” browse view, where all your docs are ordered chronologically.
- **Tags:** The sidebar has a “Tags” view, where you can see all your tags.

###### 2. How do I bring back docs to my desk/board?
- After you type the keywords to search a doc in the search bar, search results will display all the docs’ titles that fit the criteria.
- You can click the title of the docs, and they will open for you to see the full content and edit if you wish. Finally, press the "Locate” to add the doc to the desk.
- Alternatively, you can perform a search query and drag single docs or multiple docs from search results to the desk/board.
- To select single or multiple docs, activate the “select elements“ button (or the Shift + Click the element).
    - Then, drag & drop the chosen docs.
    - Or press the “add“ button on the top right corner of the selection. This button will automatically send the docs to your working space.
- If a doc is already on your desk, it will be indicated in the search view with a purple dot.
###### 3. How do I open a board?
- You can find all boards ordered chronologically in the “Boards” browse in the sidebar.
- If you’d like to search for a specific board, you can search either in the “Boards” browse view or open the Spotlight on the right corner of the top bar or use the ⌘ + Shift + K (Ctrl + Shift + K) and perform the search.
- Across all views and search options, you can see the boards’ title, the last modification date, and who created it.
- As the final step, you can click once on any board to open them.
###### 4. How do I use tags to filter my docs?
- You can click tags from the search view to filter your docs with the selected tags.
- When you select multiple tags, an “&” operation will be conducted. So, you will see the docs that include all of your search tags.
- You can combine tags with keyword searches to narrow down your search.
