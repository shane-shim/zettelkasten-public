# Working with Blocks
1. **How do I create a Block?**
When editing a doc in the text editor, you create new blocks every time you hit Enter. Each new paragraph, headline or list is a block within the editor.
All blocks that can exist in a doc can also exist on a board. You can create blocks on a board a number of different ways.
- By double-clicking on the board�
    - This will automatically create a new text block. You can just start writing or use ‘/’ to turn the block into any other kind of block.
- By using the “All blocks” button on the board toolbar, you can list all available blocks and create any type on the board.
- By hitting Enter when you have the text cursor in a block, a new and attached block will appear under the current block.
- By clicking the plus button at the bottom of a block.

1. **How do I select blocks?**
Single blocks can be selected by clicking them.
If multiple blocks are attached to each other, you can click the **:::** area on top of the blocks to select all of them at once.
To select multiple separate blocks, you can use your mouse or trackpad to draw a square around the blocks.

1. **How do I delete blocks?**
When one or more blocks are selected, you can either hit Backspace or click the Delete button on the block toolbar to delete it. The deleted block will not be possible to restore except by undoing the action.

1. **How does moving blocks work?**
Selected blocks can be moved by dragging them by the edges of the blocks, or by the **:::** drag handle. By moving blocks close to each other, they will want to connect to each other. The purple drop indicator will show where the blocks will attach.
Moving a block from a board and into a doc will result in the block being copied and pasted into the doc.
Moving blocks from a doc and into a board will result in the block being copied and pasted into the board.
Moving blocks from one doc to another will result in the block being moved.

1. **How do I turn blocks into docs?**
To turn a single block into a doc, you just need to select the block and click the “Create Doc” button in the block toolbar. If there are more than one block connected to each other, you first need to select all the blocks to be able to create a doc with the same method.
You can turn more than one block into docs by drawing a rectangle around the blocks using your mouse or trackpad, right-clicking and choosing “Create Docs”.
