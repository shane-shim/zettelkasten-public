# 240129 카카오 API 1000 지연 오류에 대해

#100-지식

상황: 프로모션 하기전 카카오 로그인이 안되어 회원가입에 문제가 발생했다.

문제: 로그인을 하면 카카오 API 1000 지연 오류 팝업이 발생 했다. 


대응: 문제 감지를 위해 빠르게 실제 로그인을 했을 때 오류 코드를 감지 했다. 

원인: 허용 IP가 등록되어 이 이슈로 인해 카카오 싱크 API가 차단되었다. 

실수 예방 방법:
허용 IP가 등록된 배경과 맥락을 돌아볼 필요가 있다. 
그리고 카카오 로그인시 오류코드의 여러가지 코드의 상황도 미리 학습해 놓으면 좋을 것 같다. 
가이드: 
[https://developers.kakao.com/docs/latest/ko/rest-api/getting-started](https://developers.kakao.com/docs/latest/ko/rest-api/getting-started)
