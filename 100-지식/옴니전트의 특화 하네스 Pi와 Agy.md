# 옴니전트의 특화 하네스 Pi와 Agy

#100-지식 #옴니전트 #하네스 #Pi #Antigravity

옴니전트 맥락에서 Pi와 Agy는 서로 다른 실행 특성을 가진 특화 하네스로 언급된다. Pi는 터미널 기반 안정성과 OS 수준 격리에, Agy는 Gemini 계열 백엔드 연동과 고속 추론 환경에 초점이 있다.

## 명시적 지식
- Pi 하네스는 tmux 기반 멀티플렉싱과 Linux bwrap, macOS Seatbelt 같은 샌드박싱 계층을 활용하는 구조로 설명된다.
- Agy는 Gemini 백엔드 전용 SDK 연동 환경을 제공하는 하네스로 설명된다.

## 경험적 피드백
Agy 초기 버전에서는 터미널 TUI 화면과 웹 대화창 사이의 입력 상태가 동기화되지 않는 병목이 있었다. 웹이나 모바일에서 보낸 메시지가 터미널 상태에 제대로 반영되지 않아, 단일 브릿지 구조로 패치해야 했다는 피드백이 있다.
