# 240105 메타 503 오류

#100-지식

상황: 메타 API 503 오류가 간헐적으로 발생한다. 

문제: 문제의 원인을 알 수 없는게 어려운 상황이다 데이터를 적제할 때 API가 끊기는 현상이다. (요즘 간헐적으로 발생하고 있음)

원인: 원인을 모르는게 미치는 부분…
