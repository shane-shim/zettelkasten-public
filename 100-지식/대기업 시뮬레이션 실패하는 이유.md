# 대기업 시뮬레이션 실패하는 이유

#100-지식

1. 실패의 기준이 무엇인지 정의해야한다. 
2. 교육전 교육중 교육후에서 교육전과 교육후에서 어떻게 설계하느냐에 따라 시뮬레이션의 만족도가 달라진다. 
3. 문제가 잘 정의되어 있느냐 피드백을 잘 주고 받았냐. 
4. ![image]()
  
  시뮬레이션이라는 것도 결국 고객의 문제와 뭘 이룰것이냐가 잘 정의되어있느냐에 따라 잘되고 안되고가 갈리는구나. 

인사이트의 가치가 없다. 인사이트를 느꼈지만 변화하지 못한경우가 많다. 결국 chage agent가 핵심. 

조직의 변화를 위해서 언프리즈 한다 얼어붙어있는 것을 녹게 만든다. 그게 워크샵 이후에 코칭을 하고 그런것도 언프리즈 한 설계다.
