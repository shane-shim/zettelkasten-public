**Background**
캠페인을 제품별로 여러 개 vs 캠페인 1개에 제품별로 세트 -> 둘 중 어느 캠페인의 효율이 더 좋은지 실험
광고 노출군과 비노출군으로 효과 측정
Agenda1. cls 결과 리뷰
2. 광고 운영
2.1) 현재 전체 광고 효율 리뷰 및 세팅 제안
2.2) 캠페인 카니발 가능성(강지영, 광희 캠페인)
2.3) 기존 캠페인의 세트를 나누는 방법
3. 현재 효율 좋은 소재 트랜드
**Next step**
1. ASC 테스트 결과 나오면 미팅 잡기(~결과 나오면, Meta)
2. 캠페인 세팅: 전체 캠페인 세팅 및 타겟팅(연령대) 테스트 제안안 전달받기(~6/27, Meta)
3. 광희 마스크케어 캠페인 이슈 확인 및 트래킹(~6/30, Meta&sy)
4. 메타의 improve 확인하여 전달(~6/27, Meta)
5. Meta studio 사이즈별 원본(1:1, 9:16) 받을 수 있는 지 + 해당 원본파일을 우리가 편집 후 광고로 활용 가능 한 지 확인(~6/23, Meta)
**Agreed**
1. 테스트 결과 : 전환, 체크아웃 시작, 콘텐츠 조회 의 지표는 simplify 캠페인이 win
Roas는 simplify 캠페인의 경우, 객단가 낮은 세트에 몰려서 lose
2. 경우에 따라 simplify 캠페인과 제품별 캠페인 세팅은 적절히 믹스하여 운영
3. 기존 캠페인의 세트 분리 세팅 시, 새로운 캠페인으로 on이 아닌 기존 캠페인에서 세트 분리
4. 두 개 이상의 캠페인을 simplify 할 시, 효율 더 좋은 캠페인에 세트 얹기
**Opinion**
1. 강지영ppl_클래식루틴 캠페인은 이번 주 효율 지켜보기
2. 제품의 기능, 사용 방법(ex step), 성분 등을 딥다이브한 소재 제작 추천(디테일한 제품 설명+특장점 강조)
3. 동영상 사이즈 1:1, 9:16 둘 다 제작 권장
4. 광희와 강지영 캠페인은 효율 떨어질 시, 비슷한 sku의 캠페인끼리 simplify 추천
**Details**
1. 광고 캠페인의 수가 많으면 오디언스 카니발의 가능성 있음.
2. 상시 캠페인의 효율이 왜 나오지 않을까? 가설1)콘텐츠 피로도, 가설2) 신규타겟 확보의 문제
3. 연령대가 30~40대에 노출이 몰려있는 것 같으니, 연령대별 타겟팅 테스트를 할 필요성이 있음.
4. 기존 캠페인의 세트를 나눠서 세팅 시, 새로 캠페인을 on 하게 되면 머신러닝 learning curb가 더 큼
5. 동영상 소재 제작 시 크리에이터 활용(크리에이터 활용이 어려울 시 라이프스타일 형식의 소재 제작)
6. 이미지 또는 슬라이드 소재 제작 시 정보 전달 내용 소구
