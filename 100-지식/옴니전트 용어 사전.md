# 옴니전트 용어 사전

#100-지식 #옴니전트 #용어사전 #AI에이전트

옴니전트 자료를 읽을 때 혼동하기 쉬운 용어는 모델, 하네스, 메타-하네스, 실행 노드, 장기 기억 저장소다. 이 용어들은 에이전트의 지능 자체와 에이전트가 실제 환경에서 행동하는 방식을 분리해서 이해하게 해준다.

## 용어
- 옴니전트(Omnigent): 이기종 AI 에이전트를 통합 제어하고 세션을 공유하기 위한 메타-하네스 프레임워크.
- 메타-하네스: 하위 하네스를 모듈처럼 교체하고 정책 제어, 세션 이동, 협업을 총괄하는 통제면.
- 하네스: 모델을 파일 시스템, 쉘, 외부 도구, 런타임과 연결하는 실행 계층. Claude Code, Pi, Antigravity 같은 도구가 여기에 해당한다.
- Pi 하네스: 터미널 기반 실행에 특화된 하네스. tmux와 OS 수준 샌드박싱을 활용하는 맥락에서 언급된다.
- Antigravity: Gemini 계열 모델을 구동하기 위한 하네스로 언급된다.
- Exe.dev: 자율 AI 코딩 에이전트 운영에 쓰이는 빠른 VM 실행 환경으로 언급된다.
- Lakebase Postgres: 에이전트 세션 상태와 대화 컨텍스트를 장기 기억처럼 보존하기 위한 저지연 OLTP 저장소로 언급된다.
