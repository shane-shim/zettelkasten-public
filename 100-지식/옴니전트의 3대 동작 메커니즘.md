# 옴니전트의 3대 동작 메커니즘

#100-지식 #옴니전트 #AI에이전트 #메타하네스 #오케스트레이션

옴니전트의 동작 메커니즘은 결합, 제어, 협업의 세 가지로 정리된다. 이 세 가지는 여러 에이전트를 단순히 한 화면에 모으는 기능이 아니라, 실행 중 교체하고 위험 행동을 막고 같은 세션을 함께 다루기 위한 메타-하네스의 핵심 능력이다.

## 메커니즘
- 결합: 실행 중에도 모델과 하네스를 교체하거나, 역할별 에이전트를 조합한다.
- 제어: 정책 검사기로 고위험 명령을 감지하고 사용자 승인 흐름을 붙인다.
- 협업: URL 기반 화면 공유, 세션 복사, 페어 디버깅처럼 같은 상태를 여러 사용자가 다룰 수 있게 한다.

## 실무 의미
옴니전트는 “에이전트 실행기”가 아니라 “에이전트 실행기를 조합하고 통제하는 계층”이다. 따라서 기능 평가는 모델 응답 품질보다 세션 이동성, 정책 강제, 협업 상태 공유가 얼마나 안정적인지를 봐야 한다.
