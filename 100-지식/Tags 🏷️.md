###### 1. What are tags?
- Tags are for categorizing or grouping multiple docs.
![image]()
###### 2. How can I create a tag?
- You can simply create a tag by typing hashtag (#) within a doc followed by the desired keyword for the tag.
- A doc can have as many tags as you wish.
- After you create your first tag in Scrintal, every time you press the hashtag (#) key, a search dropdown will appear so that you can easily select the tag you’d like to use.
- You can select one or multiple docs and activate the “Tag” button in the action bar.
###### 3. How can I delete a tag?
- You can delete the tag by deleting it from the doc’s content (backspace).
###### 4. How can I see my created tags?
- To view the tags you've created, simply access the "Tags" view in the sidebar. This view displays all of your tags, and clicking on a specific tag activates a search bar on the left, revealing all the docs associated with that tag. If you'd like to bring these tagged docs to your workspace or board, use the “select elements” button to choose the docs you want and then easily drag and drop them to the desired location in your working space.
###### 5. How can I see the docs tagged with the same tag?
- When you click on a tag in your doc, the search in the sidebar opens, showing all the docs with that tag.�
- You can click on the tags in the search panel to search for all the docs that have the selected tag. If you select more than one tag, the docs with all the selected tags will be shown in the search results.
- You can deselect a tag by clicking on the selected tags that appear below the search input field.
###### 6. How can I tag multiple docs?
- You can select multiple docs on the desk or board and right-click. Or click once on a doc activate the action bar, and then click on the three dots and select the tag option. Alternatively, you can use the shortcut `Option/ALT + T` for tagging. You can simply write the keyword for the tag without the hashtag in the tag dialog box.
