# 231007 자격지심을 보인 태도와 반응

#100-지식

상황: 혜린님이 운전 못하신다고 이야기 했을때 내가 너무 핑계를 대는듯한 과거이야기를 구체적으로 해서 자존심을 구겼다

문제: 운전 못하는 것을 당당하게 이야기하면되는데 현대판 병신이라고 자기 스스로를 비관했다.


대응: 자존심을 의도적으로 던지는 상대방을 약점을 공략하려고 하는 사람에게는 뻔뻔하고 당당하게 인정하고 별말 안하는게 좋을 것 같다.

원인: 내가 여전히 운전면허때의 사건 반항적이었던 운전면허시스템의 적응 못하는 아이라는 자격지심이 있는데 이건 내성향인 것 같다. 그걸 드러낼 필요는 전혀 없는것 같다.

실수 예방 방법:
약점을 공략하는 질문을 하는 경우 그냥 덤덤하게 침묵을 유지하는게 나에게 더 좋은 전략인 것 같다. 예전에 강보라님도 비슷한 질문을 던진 이력이 있는데 이런 사람들이 정치력이 좋을수 있음을 인지하고 오히려 레모네이드 원칙대로 상황을 역으로 활용해보는 것도 좋을 것 같다.
