# 230202 AC2 원할한 참여가 이루어 지지 않을 경우

#100-지식

Situation: 위원회 그룹끼리의 소통이 강화되고, 정보의 교류가 한쪽으로 흘러가지 않고 이미 위원회 끼리 공유되고 있음. 
Task: 문제 제기를 통해 나와의 지지자를 먼저 찾아 상위 문제를 해결할 방법을 마련해본다. 
Action: 우아하게 해당 이슈를 제기해보고, 콜투액션 문구로 지지자를 찾아본다. 

Result(예측): 왠지 나를 지지하는 사람과 나를 배척하는 사람 이렇게 이분화 되지 않을까 생각한다. (이게 좋은걸까) 
여태까지 진행해온 것이 있기 때문에 지금의 상황을 사람들은 더 편안하게 생각하는 사람이 많을 듯 하여 새로운 시도에 진저리를 칠 것 같다.
 Result(실제): 나의 문제를 해결해주려고, 많은 사람들이 댓글을 달아주었다. 심지어 위로의 문자들도 많이 왔었다. 내가 예상했던것보다 이분법으로 진행되지 않고 결과적으로 의사결정을 더 원할하게 진행될 수 있었다. 

Reflection: 내가 상황을 너무 부정적으로 본 것이 아닐까? 어떻게 보면 내가 초반 소외되었던 이유는 사람들은 편안하게 해준 것이 아닌 불안감을 야기시켜 신뢰를 잃었던 것 아닐까? 사람들과의 관계를 좀 더 신경써야 겠다는 반추를 해본다.

기존의 나라면? 평소의 나라면 이런 상황에서 침묵을 유지하고, 회피했을 가능성이 있고, 만약 문제를 개선하려고 한다면 좀 더 공격적으로 질문하고, 더 적극적으로 충돌 했을 것 같다.
그 과정에서 충돌이 나면 경쟁 했거나 좋지 않은 방향으로 이루어질 가능성이 높을 것 같다. (충돌과정에서 내가 이기더라도)
