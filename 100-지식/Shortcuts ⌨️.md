# Shortcuts ⌨️

#100-지식 #scrintal_help

#scrintal_help 
Here you can find all of the keyboard shortcuts that exist in Scrintal. 👇
###### 1. Global Shortcuts

---
- Search in Library
    - MacOS: CMD + F
    - Other: CTRL + F
- Open spotlight
    - MacOS: CMD + SHIFT + K
    - Other: CTRL + SHIFT + K
- Toggle Sidebar
    - MacOS: CMD + SHIFT + E
    - Other: CTRL + SHIFT + E
- Close all open doc windows
    - MacOS: Shift + ESC
    - Other: Shift + ESC
- Clear desk/board
    - MacOS: CMD + Shift + Backspace
    - Other: CTRL + Shift + Backspace
- Organize desk
    - MacOS: CMD + Shift + O
    - Other: CTRL + Shift + O
- Move the cursor to the next open doc
    - MacOS: CMD + K
    - Other: CTRL + K
- Move the cursor to the previous open doc
    - MacOS: CMD + J
    - Other: CTRL + J
- Zoom In
    - MacOS: CMD + Plus (+)
    - Other: CTRL + Plus (+)
- Zoom Out
    - MacOS: CMD + Minus (-)
    - Other: CTRL + Minus (-)
- Create a new doc
    - Press C key
- Create a new board
    - Press B key
- Create a new daily doc
    - Press D key
- Create a new column
    - Press K key
- Create a new link
    - Press L key
- Toggle dragging
    - Press M key
- Quick drag
    - Press and hold the spacebar and drag
- Select multiple docs from the sidebar
    - Shift + Click
- Open a doc on the sidebar in focus mode
    - MacOS: CMD + Click
    - Other: CTRL + Click
- Remove a starred item from the sidebar
    - MacOS: Option + Click
    - Other: Alt + Click
- Open/close the left sidebar
    - MacOS: CMD + SHIFT + E
    - Other: CTRL + SHIFT + E
- Open/close the right sidebar
    - MacOS: CMD + SHIFT + U
    - Other: CTRL + SHIFT + U

###### 2. Desk/Board Shortcuts

---
- Select all docs
    - MacOS: CMD+A
    - Other: CTRL+A
- Undo
    - MacOS: CMD + Z
    - Other: CTRL + Z
- Redo
    - MacOS: CMD + SHIFT + Z
    - Other: CTRL + SHIFT + Z
- Copy elements
    - MacOS: CMD+C
    - Other: CTRL+C
- Cut elements
    - MacOS: CMD+X
    - Other: CTRL+X
- Paste elements
    - MacOS: CMD+V
    - Other: CTRL+V
- Fold/unfold selected docs
    - Press F key
- Change the doc layout to the title layout of the selected docs
    - Press L key
- Tag selected docs
    - MacOS: Option + T
    - Other: Alt + T
- Open selected docs
    - MacOS: Option + O
    - Other: Alt + O
- Change the color of the selected docs
    - MacOS: Option + C
    - Other: Alt + C

###### 3. Text Editor Shortcuts

---
- Close doc window
    - ESC
- Close focus mode
    - ESC
- Close focus mode split view
    - ESC
- Enter focus mode
    - MacOS: CMD + Shift + Enter
    - Other: CTRL + Shift + Enter
- Search in text
    - MacOS: CMD + F
    - Other: CTRL + F
- Turn selected text into a link
    - MacOS: Option + L
    - Other: Alt + L
- Open the link under the cursor (external or internal)
    - MacOS: Option + O
    - Other: Alt + O
- Bold text
    - MacOS: CMD + B
    - Other: CTRL + B
- Italic text
    - MacOS: CMD + I
    - Other: CTRL + I
- Underlined text
    - MacOS: CMD + U
    - Other: CTRL + U
- Strikethrough text
    - MacOS: CMD + SHIFT + X
    - Other: CTRL + SHIFT + X
- Undo
    - MacOS: CMD + Z
    - Other: CTRL + Z
- Redo
    - MacOS: CMD + SHIFT + Z
    - Other: CTRL + SHIFT + Z
- Bullet list
    - SHIFT + CTRL + 8
- Ordered list
    - SHIFT + CTRL + 9
- Horizontal Rule
    - MacOS: CMD + _
    - Other: CTRL + _
For further text editor functionality and hotkeys, see the [Text Editor ✍️](Text%20Editor%20%E2%9C%8D%EF%B8%8F.md).
