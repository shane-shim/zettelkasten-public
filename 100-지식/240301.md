# 240301

#100-지식

지안이 침대에서 책을 읽고 끄적이다가 밤에 자는 것은 매우 생산적인 일이었다. 이상하게 책이 잘 읽히고, 혼자 고요하게 집중할 수 있던 시간이었다. 앞으로도 하루에 하나씩 명시적 지식들을 인출하고 그걸 인지부하를 실무에서 줄이는데 노력한다면 어제보다 많이 발전하지 않을까 싶다. 

사무실을 정리했다. 끝까지 마무리를 잘하려고 노력했던 것 같다. 내가 책임감을 가지고 꼼꼼히 잘 수행했던 것 같다. 강남 패파보다는 안좋다고 생각했겠지만, 마치 유배온 것 처럼 집과 가까운 곳에서 집중을 잘 할 수 있었던 것 같다. 외적이고 물질적인 것에 신경쓰기보다 나와 잘맞는 환경,사람, 공간 그걸 찾는 핵심 관찰력을 길러야겠다는 생각. 그리고 요즘은 맨날 복싱가고 행복한 하루.
