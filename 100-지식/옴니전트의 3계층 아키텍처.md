# 옴니전트의 3계층 아키텍처

#100-지식 #옴니전트 #아키텍처 #AI에이전트 #하네스

옴니전트는 AI 에이전트 스택을 모델, 하네스, 메타-하네스의 3계층으로 분리해 각 계층이 독립적으로 발전할 수 있게 한다. 이 분리는 특정 모델이나 도구에 종속되지 않고, 여러 실행 환경을 교체 가능한 구성 요소로 다루기 위한 전제다.

## 계층
- 모델: Claude, GPT, Gemini 같은 추론 엔진이며 두뇌 역할을 한다.
- 하네스: 모델을 파일 시스템, 쉘, 코드베이스, 외부 도구와 연결하는 실행 신체다.
- 메타-하네스: 여러 하네스와 세션을 결합하고 정책을 적용하며 협업을 조율하는 통제면이다.

## 동작 메커니즘
- 결합성: 이기종 에이전트와 모델을 교체하거나 교차 배치한다.
- 제어성: 상태 기반 정책 필터로 고위험 명령 실행을 막고 승인 흐름을 붙인다.
- 협업성: 세션 공유, 페어 디버깅, 세션 복사와 같은 협업 형태를 지원한다.
