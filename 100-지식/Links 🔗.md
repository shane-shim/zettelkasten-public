###### 1. What are Linked Docs?
Linked docs are bi-directional connections that help you create a web of knowledge.
###### 2. How do I create a Linked doc?
To create a Linked Doc, simply type the plus (+) sign followed by the title of the doc you want to refer to. When you start typing after the plus (+) sign, the search dropdown will open, showing all the docs and boards in your library. You can select one of the options to link. Alternatively, if you add the plus (+) sign in front of any word and press enter, you will create a Linked Doc. If the doc title doesn’t exist, you can create a new doc with that title.
If you prefer a more visual approach to creating links while your docs are displayed on your desk or board, you can do so effortlessly. Just drag the purple dot from doc A to doc B to establish a direct link between them. Alternatively, if you wish to create a new doc (Doc C) and link it automatically, drag the purple dot to an empty space on your board. This intuitive method simplifies the process of establishing connections between your docs, making it a seamless experience.
Linked docs are visually represented with arrows. The doc at the start point of an arrow is the doc referencing the doc at the end point of the arrow.
- The arrow represents the link to the doc. (You can think of the reverse arrow as the backlink.)
- If the link has arrows on both sides, it means the two docs link to each other.

###### 3. How can I see the links of a single doc?
You can see a doc’s links in two ways.
- You can double-click and open a doc. Links are displayed at the bottom of an open doc (if the doc has any links).
- You can click once on a doc and activate the action bar. Then click on the search links option, which is the furthest right option.
- Open the right sidebar and keep track of every link and backlink.

###### 4. How can I delete links?
- You can delete links by simply deleting the linked doc name from the text editor.
- If both docs are on display, you will see the link on display. Click the link onc, and the delete button will show. Click it, and the link will be deleted.

###### 5. Can I link boards to a doc?
Yes, you can link boards to a doc. You can press (+) sign and type the title of the board you would like to link.
###### 6. Can I link boards to boards?
Yes, you can link boards to boards. You can press (+) button on the left side of your board. This will create a new board. If you want to connect two existing boards, go to board A, search for board B, and drag and drop the element to board A. If needed, repeat the action on board B.
###### 7. What’s the difference between links and backlinks?
In Scrintal, there are two types of links:
- Links
    - These are the links from your doc to another doc
- Backlinks
    - These links from another doc to your current doc. Backlinks allow you to go to docs that originally refer to the doc you are looking at.
###### 8. How can I change the direction of a link?
You can change the direction of a link by opening the doc and removing the link. Then, you can open the doc that you would like to be the new source of the link, and you can add the link to the doc you want.
If the link is on display, simply click on the link once and select the option “reverse”.
